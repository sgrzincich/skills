# Clear Writing

Apply Orwell's rules, then review the draft. The rules serve the reader. Where the context calls for something else, follow the context.

## 1. Read the context first

Before changing a word, decide:

- **Audience**: what readers already know and which terms they use.
- **Genre**: its conventions. A methods section, an API reference, a contract, a commit message, and an essay each have different ones.
- **Voice**: the author's register and tone. Keep it. Clear does not mean casual.

These decide how strictly each rule applies.

## 2. Orwell's rules

From George Orwell, "Politics and the English Language" (1946):

> One can often be in doubt about the effect of a word or a phrase, and one needs rules that one can rely on when instinct fails. I think the following rules will cover most cases:
>
> 1. Never use a metaphor, simile, or other figure of speech which you are used to seeing in print.
> 2. Never use a long word where a short one will do.
> 3. If it is possible to cut a word out, always cut it out.
> 4. Never use the passive where you can use the active.
> 5. Never use a foreign phrase, a scientific word, or a jargon word if you can think of an everyday English equivalent.
> 6. Break any of these rules sooner than say anything outright barbarous.

Where context overrides a rule:

- **Passive voice**: use it when the actor is unknown or irrelevant ("The samples were centrifuged at 4 °C"), when the genre expects it (as in lab methods sections), or when it moves the familiar part of a sentence to the front (see section 3). Never use it to hide who is responsible.
- **Jargon**: keep a term the audience uses when no plain word is as precise. For a mixed audience, define it at first use.
- **Cutting**: keep words that carry precision: units, conditions, scope, and hedges the evidence requires.

## 3. Review the draft

Check the draft at three levels.

**Words: find hidden verbs.** Look for nouns built from verbs or adjectives, often ending in -tion, -ment, -ance, or -ity: "make a decision", "perform an analysis of", "the implementation of". Turn each back into a verb ("decide", "analyze", "implement") unless it names a concept the text discusses.

**Sentences: put the topic first.**

- Name what each sentence is about, and make that the grammatical subject. If the subject is filler ("There is", "It is") or something the sentence is not really about, rewrite it.
- Start each sentence with what the reader already knows, usually something from the sentence before. End it with the new information. If the familiar part comes last, reorder the sentence, using the passive if that is what it takes.

**Paragraphs: one point each.**

- State each paragraph's point in one sentence. Move or cut any sentence that does not serve it.
- Compare the first and last sentences. If they discuss different things, the paragraph has drifted; split it or refocus it.

## 4. Output

- Preserve meaning, facts, and the author's voice. Do not add claims.
- If an edit might change the meaning, flag it instead of making it.
- Return the revised text. When reviewing rather than rewriting, list the specific problems and the fix for each.
